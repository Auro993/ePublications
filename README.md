# 📚 E-Book Management System

A dynamic web-based **E-Book Management System** built using **Java Servlets and JSP**, allowing users to browse, search, and manage digital books efficiently.

---

## 🚀 Features

- 🔐 User Registration & Login Authentication  
- 📖 Browse and View Book Details  
- 🔍 Search Books by Category  
- 🛒 Add to Cart & Remove from Cart  
- 💳 Checkout and Order Processing  
- 📂 Category-wise Book Listing  
- 🔄 Session Management using Servlets  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JSP  
- **Backend:** Java Servlets  
- **Database:** MySQL (JDBC)  
- **Server:** Apache Tomcat  
- **Architecture:** MVC Design Pattern  

---
## ⚙️ How to Run the Project

1️⃣ **Import the project** into *Eclipse / IntelliJ*  

2️⃣ **Configure Apache Tomcat Server**  

3️⃣ **Setup MySQL Database**
   - Create a new database  
   - Update DB credentials in `DBConnect.java`  

4️⃣ **Run the project** on the server
